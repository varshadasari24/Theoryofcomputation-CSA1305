# Context Free Grammar (CFG) Simulation in C

## Aim

To write a C program to check whether a given string belongs to the language defined by the Context Free Grammar (CFG):

```
S → 0S1 | ε
```

## Project Description

This project implements a C program to verify whether a given binary string belongs to the language generated by the Context Free Grammar (CFG) **S → 0S1 | ε**. The grammar generates strings containing an equal number of `0`s followed by an equal number of `1`s, with all `0`s appearing before the `1`s.

## Features

- Checks whether the input string belongs to the given CFG.
- Accepts binary strings over the alphabet `{0,1}`.
- Rejects invalid symbols.
- Verifies that the number of `0`s equals the number of `1`s.
- Ensures all `0`s appear before any `1`.
- Displays whether the string is accepted or rejected.

## Language

- C

## Algorithm

1. Read the input string.
2. Verify that every character is either `0` or `1`.
3. Count the number of leading `0`s.
4. Count the number of trailing `1`s.
5. Check that all `0`s appear before the first `1`.
6. Verify that the number of `0`s equals the number of `1`s.
7. If all conditions are satisfied, accept the string.
8. Otherwise, reject the string.

## Time Complexity

**O(n)**

where **n** is the length of the input string.

## Space Complexity

**O(1)**

## Sample Input

```text
000111
```

## Sample Output

```text
Accepted
```

## Result

The C program successfully checks whether a given binary string belongs to the language defined by the Context Free Grammar **S → 0S1 | ε**.
